# ADHD Weekly Planner Pack — Start here

Printable **markdown planner pages** designed for ADHD-friendly weeks: fewer decisions, clearer priorities, tiny habits.

## What's included

| File | Purpose |
|------|---------|
| `pages/01-weekly-planner.md` | Mon–Sun layout + brain dump |
| `pages/02-priority-matrix.md` | Urgent/important matrix (Eisenhower-style) |
| `pages/03-habit-mini-tracker.md` | 7-day habit mini-tracker |
| `PRINTING.md` | Print / PDF tips |

Also: `LICENSE` (MIT) · `listing-gumroad.md`

## Quick start

1. Duplicate the weekly planner each Sunday (or Monday).
2. Cap **Must-do** at 3 items per day.
3. Use the matrix when everything feels urgent.
4. Track only **3–5 habits** — not 20.

## Philosophy (short)

- Externalize the to-do list (don't keep it in working memory).
- Prefer "good enough" completion over perfect systems.
- Celebrate streaks of *showing up*, not perfection.
